# 前端业务应用

Vue 3 + TypeScript + Vite 的单页业务应用。页面显示“报警管理系统”；使用仓库样例时明确标注“仅使用合成数据”。应用以项目为业务边界，提供项目创建/搜索/归档、图形化字段映射与异常行修正、可刷新恢复的人工补录、分析看板、报警详情与处置、审计和报告闭环。

统计、详情和处置状态均来自 Java API/PostgreSQL 事实源，前端不复制业务计算。关联事件链明确显示为规则建议，不声称已确认根因。处置仅允许 `OPEN → IN_PROGRESS → CLOSED` 及 `IN_PROGRESS → OPEN`，每次操作都要求操作者和说明。

## 环境

- Node.js 22.12 或更高版本
- npm 9 或更高版本
- 开发时 Vite 将同源 `/api` 请求代理到本机 `127.0.0.1:8080` 的 Java 主系统
- 生产构建产物由 Java 主系统托管

## 开发与验证

```bash
npm ci
npm run dev
npm test -- --run
npm run build
```

启动 Java 主系统后运行 `npm run dev`，访问 `http://127.0.0.1:5173`。浏览器始终请求同源 `/api/v1/**`；代理目标仅用于本地 Vite 开发，不进入生产构建。

页面固定呈现六步首次使用引导，每一步都由当前项目、真实批次、分析、处置和报告下载状态推进：

1. 创建或选择项目；项目切换会清空前端当前批次，随后按 `project_id` 重新加载。
2. 选择合成 CSV/TXT/XLSX。
3. 从源表头下拉框生成目标字段映射并预览；错误行可按中文字段直接修正后随原文件重新全量校验，页面不要求填写 JSON。
4. 全文件校验通过后确认导入。
5. 开始分析，查看趋势、占比、区域排名和装置分布；看板可打印或导出 CSV。
6. 分配责任人、提交处置并下载 PDF/XLSX 报告。

项目设置只开放固定报告模块和当前导入器能执行的校验规则。归档项目只读；只有从未产生业务数据的归档空项目才显示精确编号确认删除入口。人工补录从服务端重新加载，只允许在分析前修订，作废保留事实与理由。API 继续使用稳定机器值，页面统一通过中文词典显示项目、导入、分析、报警、处置和审计状态。

`dist/`、测试覆盖率和 `node_modules/` 均为可再生成内容，不提交 Git。
