# 前端业务应用

Vue 3 + TypeScript + Vite 的单页业务应用。页面显示“报警管理系统”；使用仓库样例时明确标注“仅使用合成数据”。应用提供健康状态、文件导入、分析、看板、报警筛选/详情、关联事件链和人工处置闭环。

统计、详情和处置状态均来自 Java API/PostgreSQL 事实源，前端不复制业务计算。关联事件链明确显示为规则建议，不声称已确认根因。处置仅允许 `OPEN → IN_PROGRESS → CLOSED` 及 `IN_PROGRESS → OPEN`，每次操作都要求操作者和说明。

## 环境

- Node.js 22.12 或更高版本
- npm 9 或更高版本
- 开发时 Vite 将同源 `/api` 请求代理到本机 `127.0.0.1:8080` 的 Java 主系统
- 生产构建产物由 Java 主系统托管

## 开发与验证

```bash
npm ci
npm run dev
npm test -- --run
npm run build
```

启动 Java 主系统后运行 `npm run dev`，访问 `http://127.0.0.1:5173`。浏览器始终请求同源 `/api/v1/**`；代理目标仅用于本地 Vite 开发，不进入生产构建。

页面主流程：

1. 选择合成 CSV/TXT/XLSX，完成校验预览和确认导入。
2. 对 `IMPORTED` 批次开始分析；失败时按页面提示恢复服务后重试。
3. 查看总数、小时趋势及优先级、区域、单元、噪声和原因建议分布。
4. 按字段筛选和分页查看报警，进入详情核对规范化字段、原始行、证据与关联链。
5. 填写操作者和说明，完成处理中、关闭或退回，并核对处置历史。

`dist/`、测试覆盖率和 `node_modules/` 均为可再生成内容，不提交 Git。
