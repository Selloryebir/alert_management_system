# 报警管理系统业务使用手册

## 1. 手册用途

本手册面向不需要理解源码的业务人员，说明如何在 Windows 11 x64 电脑上使用报警管理系统完成一次可重复的业务演示。安装、启动、备份、恢复验证和实例清理的完整命令见 [Windows 部署与运维手册](windows-deployment-operations.md)。

本系统当前处理离线报警文件。随包样例均为合成数据，不包含真实厂名、人名、生产位号或生产数据。算法结果是可解释的分析建议；“原因建议”和“关联事件链”不代表已经确认工业根因。

## 2. 使用前准备

开始前请向部署人员确认：

- 系统已在本机启动；
- 浏览器地址为 `http://127.0.0.1:8080`；
- 已取得自己的账号和密码；
- 已取得要使用的项目权限；
- 本次演示使用发布包 `samples` 目录中的合成样例。

Windows 原生包首次启动时会建立管理员账号 `admin`，临时密码保存在安装目录下的 `data\secrets\bootstrap-admin-password.txt`。该文件属于受限凭据，不得发送、截图或放入报告。首次登录后必须按页面提示修改密码。

## 3. 角色与可见入口

| 角色 | 主要能力 |
|---|---|
| 系统管理员 | 管理账号、创建项目、管理项目成员、执行全部项目业务操作、查看全局审计、复位演示数据、查看数据与备份状态 |
| 项目负责人 | 管理所属项目资料、生命周期和现有成员，执行所属项目的导入、分析、分类修订、处置和报告操作 |
| 分析人员 | 在所属项目中执行导入、分析、分类修订、处置和报告操作，不管理账号、项目资料或全局审计 |

页面会按当前账号职责隐藏无权使用的入口。若知道某个地址或标识但仍收到“无权执行”或“未找到”，不要重复尝试，请联系系统管理员确认项目成员关系。

## 4. 首次十分钟演示

以下路径使用系统管理员账号和 300 行 UTF-8 CSV 合成样例。页面为单页工作台，没有侧边菜单；按顺序从页面顶部向下滚动即可。

1. 打开 `http://127.0.0.1:8080`。
2. 使用 `admin` 和临时密码登录，按页面提示填写当前密码、新密码并再次确认。
3. 在“选择当前工作项目”中选择“默认演示项目”；也可点击“新建项目”创建一个演示项目。
4. 在“文件导入与字段映射”中选择：

   ```text
   samples\smoke\synthetic_smoke_utf8.csv
   ```

5. 点击“读取表头并预览”，核对字段映射、总行数、有效行数和错误数。
6. 预览状态为可导入且错误数为 0 时，点击“确认导入”。
7. 在“报警业务闭环”中找到刚导入的批次，点击“开始分析”。
8. 若页面提示仍在分析，稍后点击同一批次的“刷新分析”；完成后页面自动显示“分析总览”。
9. 在“报警列表”点击任一“查看详情”，检查原始行、规则证据和相关事件链。
10. 在“人工处置”中把责任人账号填写为 `admin`，填写处置说明，依次点击“开始处理”和“关闭报警”。
11. 向下滚动到“整次分析报告”，分别点击“下载 PDF”和“下载 XLSX”。
12. 系统管理员可展开“数据与备份”查看容量和恢复点；网页提示“待运行完整校验”时，以部署人员运行 `scripts\backup-status.ps1` 的结果为准。

完成后，应能看到导入批次、分析看板、报警详情、处置历史和两类已下载报告。下载文件通常由浏览器保存到当前用户的“下载”目录，实际位置以浏览器提示为准。

## 5. 登录、改密与退出

### 5.1 登录

在“登录报警管理系统”中输入账号和密码后点击“登录”。账号使用小写英文字母、数字、点、下划线或短横线。

连续 5 次密码错误会锁定账号 15 分钟。被锁定时应停止重复输入，等待锁定结束，或联系系统管理员在“账号与项目权限”中重置临时密码。

### 5.2 首次修改密码

临时密码账号只能看到账号信息、修改密码和退出入口。新密码必须满足：

- 长度为 12–64 个字符；
- 不等于账号名；
- 不等于当前密码；
- 两次输入完全一致。

保存成功后系统会使用新密码重新建立会话，原有旧会话失效。

### 5.3 日常改密和退出

展开页面顶部的当前账号区块，可点击“修改密码”或“退出登录”。会话空闲超时或账号状态变化时，页面会提示重新登录；未保存的表单内容可能需要重新填写。

系统不提供自助注册、邮件找回或短信找回。忘记密码时联系系统管理员重置。唯一系统管理员应安全保存当前密码，并由组织按职责保管至少一个可用的管理员账号。

## 6. 项目工作区

### 6.1 创建项目

只有系统管理员能看到“新建项目”。创建时填写：

- 项目编号；
- 项目名称；
- 客户名称；
- 厂区；
- 装置。

点击“创建并选中”后，导入、分析、处置和报告都会归入该项目。项目编号必须唯一。

### 6.2 选择和搜索项目

在“选择当前工作项目”中可按编号、名称、客户或厂区搜索，再点击对应项目的“选择”。页面显示“当前：项目名称”后再开始导入。

勾选“包含已归档项目”可以查看归档项目。归档项目只能查看历史数据，不能新增导入或启动分析。

### 6.3 项目设置和成员

系统管理员或项目负责人可打开“项目设置”，维护项目资料、报告抬头、报告内容和有限的导入校验规则。

系统管理员可在“账号与项目权限”中新建账号并加入当前项目。项目负责人可调整或移除现有成员；新增账号并首次加入项目由系统管理员完成。

“导出项目清单”下载的是当前项目资料和统计 JSON，不是数据库备份。

## 7. 文件上传、字段映射与纠错

### 7.1 支持的格式

| 格式 | 要求 | 随包示例 |
|---|---|---|
| CSV | 带表头；支持 UTF-8（含 BOM），合成样例另含 GB18030 中文文件 | `samples\smoke\synthetic_smoke_utf8.csv`、`samples\smoke\synthetic_smoke_gb18030.csv` |
| TXT | 带表头，字段以制表符分隔 | `samples\smoke\synthetic_smoke_utf8.txt` |
| XLSX | 第一行是表头，读取第一个可见工作表，不执行公式或宏 | `samples\smoke\synthetic_smoke.xlsx` |

正式支持上限为：单个文件 50 MiB、100,000 行、256 列、8 个 XLSX 工作表。超过限制、文件畸形或解析超时会在写入前返回中文错误，不会只导入部分数据。

### 7.2 预览和映射

1. 先选中一个“使用中”的项目。
2. 在“文件导入与字段映射”中选择文件。
3. 点击“读取表头并预览”。
4. 在“字段映射”中核对系统目标字段与源表头。
5. 未识别的必填字段使用中文下拉框选择正确源表头；可选字段可保留“不映射”。
6. 点击“按当前映射重新校验”。

业务人员不需要编辑 JSON。不要仅凭列的位置猜测含义；不确定的厂商字段应由数据负责人确认。

### 7.3 错误和页面内修正

错误表会显示源行、字段、错误类型和中文说明。对页面列出的可修正错误，可填写目标字段修正值，再点击“按修正值重新全量校验”。修正只作用于本次导入结果；原始文件和原始文本仍会保留用于追溯。

当状态变为可导入且没有阻断错误时，点击“确认导入”。有阻断错误时不会出现“确认导入”，也不会形成半批次业务数据。

发布包 `samples\invalid` 目录中的文件用于演示错误提示，不应作为正常业务样例确认导入。

## 8. 分析、看板与详情

### 8.1 启动或刷新分析

确认导入后，向下滚动到“报警业务闭环”。不调整参数时直接点击当前批次的“开始分析”，系统使用 hybrid-v2 推荐参数。

“加载并调整参数”仅用于了解规则的业务人员。越界参数会被服务端拒绝。分析尚未完成时，页面不会自动伪装为完成；稍后点击“刷新分析”。失败批次会显示“重试分析”，应先确认页面“系统运行状态”中的算法服务恢复正常。

### 8.2 看板

完成后“分析总览”显示：

- 报警总数、待处理、处理中、已关闭和关联事件链数；
- 小时趋势；
- 优先级、区域和单元分布；
- 报警类型及原因建议分布。

“打印或保存为 PDF”使用浏览器打印功能，只保存当前看板；“导出看板数据”下载 CSV。它们不等同于下方的完整分析报告。

### 8.3 报警列表和详情

报警列表支持按优先级、区域、单元、报警类型、原因建议、处置状态和责任人账号筛选。点击位号或描述下方的“查看详情”，可以查看：

- 规范化字段和源行号；
- 原始行；
- 算法标签、规则分数和规则证据；
- 相关事件链；
- 当前责任人和处置历史。

相关事件链只说明时间窗口和统计关联。页面和报告中的原因类别是建议，不得作为自动确认的工业根因。

## 9. 人工分类修订与处置

### 9.1 分类修订

在报警详情的“人工分类修订”中选择报警类型、报警分类和原因建议，填写修订理由后点击“保存分类修订”。

人工修订会成为当前有效结论，并影响看板和报告；算法原始结论仍保留，便于复核。

### 9.2 责任人账号

“责任人”必须填写当前项目中处于启用状态的成员账号，不是展示名。系统管理员或项目负责人可在“账号与项目权限”的成员表中查看账号；分析人员应使用自己的登录账号，或向项目负责人取得准确账号。

在管理员首次演示中可填写：

```text
admin
```

若提示“责任人必须是该项目的有效成员账号”，请核对拼写、账号状态和项目成员关系，不要填写任意姓名绕过。

### 9.3 状态流转

1. 填写责任人账号和处置说明。
2. 待处理报警点击“开始处理”。
3. 处理中报警完成业务核对后点击“关闭报警”。
4. 需要继续调查时可点击“退回待处理”。

每次操作的操作者来自当前登录账号，页面不要求重复填写。处置历史保存时间、前后状态、责任人、操作者和说明。

## 10. 报告、审计与演示复位

### 10.1 完整分析报告

分析完成并加载后，在“报告、审计与演示数据维护”的“整次分析报告”中点击：

- “下载 PDF”；
- “下载 XLSX”。

报告为空、生成失败或服务不可用时，页面会保留当前分析并给出中文原因。不要把失败提示或零字节文件作为成功报告。

### 10.2 审计记录

系统管理员和项目负责人可按事件类型刷新只读审计记录。分析人员不能读取审计。审计操作者来自登录会话，不等于报警文件中的“源操作员”。

### 10.3 演示数据复位

只有系统管理员能看到“危险操作：复位演示数据”。该操作会清空系统内全部演示项目的导入、分析、处置和审计数据，不只影响当前项目。

确需复位时输入：

```text
RESET_DEMO
```

再点击“复位全部演示数据”。复位不会删除发布包样例和已有数据库备份。执行前应先下载需要保留的报告，并确认没有其他人员正在使用系统。

## 11. 数据与备份状态

系统管理员可展开“数据与备份”，点击“刷新状态”查看：

- 数据库容量；
- 恢复点数和备份总容量；
- 最近成功时间；
- 恢复点文件、时间、容量和元数据状态；
- 当前部署方式及操作提示。

网页只读取恢复点元数据和文件大小，不读取大型备份完成 SHA-256。显示“待运行 `backup-status.ps1` 完整校验”时，不代表恢复点已校验通过。请通知部署人员按 [Windows 部署与运维手册](windows-deployment-operations.md#8-备份与完整性检查)运行状态脚本。

网页没有创建备份或覆盖恢复当前数据库的按钮。Windows 原生包只提供受控备份和隔离恢复验证。

## 12. 停止系统

业务操作和报告下载完成后，先关闭或保存正在编辑的页面，再在安装目录的 PowerShell 中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\stop.ps1
```

看到“当前发布包服务已停止”后可以关闭浏览器。停止不会删除项目、业务数据或备份；以后仍可用 `scripts\start.ps1` 重新启动。

## 13. 常见错误处理

| 现象 | 处理方法 |
|---|---|
| 无法打开网页 | 确认地址为 `http://127.0.0.1:8080`；请部署人员确认启动命令已显示成功，并检查 `logs` 目录。不要改成局域网 IP。 |
| 登录失败 | 核对账号和当前密码；连续错误后停止尝试。锁定 15 分钟可等待，或由系统管理员重置临时密码。 |
| 页面提示登录失效 | 重新登录。改密、管理员重置密码或账号停用后，旧会话会立即失效。 |
| 没有项目或看不到按钮 | 联系系统管理员确认账号已加入项目及职责；归档项目为只读。 |
| 文件无法确认导入 | 查看错误表中的源行、字段和原因，修正映射或错误值后重新全量校验。 |
| 分析仍在进行 | 稍后点击“刷新分析”，不要重复上传同一文件制造新批次。 |
| 分析失败 | 展开“系统运行状态”，确认算法服务；服务恢复后对失败批次点击“重试分析”。 |
| 责任人无效 | 输入当前项目有效成员的账号，而不是展示名。 |
| 报告下载失败 | 保留当前分析，确认主系统状态后重试；不要把浏览器看板打印当作完整分析报告。 |
| 备份状态显示待校验 | 由部署人员运行 `scripts\backup-status.ps1`；网页元数据正常不等于 SHA-256 通过。 |
| 页面中文异常或出现未处理错误 | 记录发生时间和操作步骤，保留 `logs` 目录，停止继续写入并交由部署人员处理。 |

## 14. 使用边界

- 当前只支持离线 CSV、制表符 TXT 和 XLSX，不提供 OPC、实时 DCS 或第三方报警流入口。
- 系统没有工业设备、联锁、摄像头、门禁或通知平台的控制写入能力。
- 合成数据结果不能用于宣称真实工业准确率、7×24 小时稳定性或法规合规。
- PDF/XLSX 是业务分析报告；项目过程 DOCX/PDF 是项目交付文档，两者用途不同。
- 本手册不承诺任意浏览器、任意 Office/WPS 版本或 Windows Server 兼容性；最终支持范围以绑定发布候选的验收记录为准。
