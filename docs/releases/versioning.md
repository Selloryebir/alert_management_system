# 版本与标签策略

## 版本语义

- `v0.1.0`：M0–M7 可运行功能基线，已通过 PR #1 合入 `main`。
- `v0.2.0`：M9 可泛化算法模型通过后的功能标签。
- `v0.5.0`：M10 项目化业务与全中文 UX 通过后的功能标签。
- `v0.8.0`：M12 安全部署、恢复和可靠性通过后的可部署标签。
- `v1.0.0-rc.1`：M14 Windows 业务用户终验通过后的发布候选标签。
- `v1.0.0`：只有最终 PR 合入 `main` 且人工批准正式发布后创建。

## 标签门槛

标签使用 annotated tag，并且只指向满足以下条件的提交：

1. 功能阶段已形成 `dev` 非快进合并检查点；
2. 该检查点的阶段命令和适用远端 CI 全部成功；
3. 证据文件记录完整 SHA 和结果；
4. 工作树干净，远端 `dev` 精确可达；
5. 标签名称尚不存在。

不在文档提交、失败候选、PR 临时合并引用或未核验工作树上打标签。标签不是替代测试的进度标记。
