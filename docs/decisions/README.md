# 架构与产品决策记录

下列决策已由本轮人工授权或由已授权目标直接约束，开发智能体应按“已接受”执行。若要改变，需新增带日期的 ADR，说明触发证据、影响和迁移方式；不得直接覆盖历史决定。

## ADR-001：灾后重建身份与历史材料隔离

- 状态：已被 ADR-008 取代
- 决策：产品统一标识为“2026 年灾后重建 Demo”。历史 PDF/DOCX 是证据和候选来源，不是实现规格；PDF 占位代码和无关项目材料不进入实现上下文。
- 原因：源码已经遗失，历史材料存在编撰期冲突且结论未经当前实现验证。
- 影响：只有产品事实层的 `采用`、`调整后采用` 项可进入任务；界面、说明和报告不得暗示找回旧源码。

## ADR-002：多专业职责、少运行组件

- 状态：已接受
- 决策：Java 主系统 + Python 算法服务 + PostgreSQL + Vue；保持算法、后端、前端、工程、测试五类职责，但不拆微服务群。
- 原因：既能体现现实团队和技术边界，也能缩短 Windows 演示交付链路。
- 影响：Java 独占业务数据库写入，Python 通过版本化 HTTP 契约纯计算，Vue 产物由 Java 托管。

## ADR-003：PostgreSQL 替代历史 MySQL 路径

- 状态：已接受
- 决策：新实现以 PostgreSQL 17 为唯一业务事实源，模式由 Flyway 管理。
- 原因：这是本轮确定的新实现架构；灾后重建不承担与遗失数据库的兼容迁移。
- 影响：不得同时维护 MySQL 方言、双数据库配置或无验证收益的兼容层。

## ADR-004：Windows 原生包优先，Docker 次级

- 状态：已接受
- 决策：首要交付是 Windows 11 x64 自包含运行包；Docker Compose 复用同一构件和配置语义，优先级为 P1。
- 原因：审核电脑已经确定，原生启动最符合现场需求。
- 影响：审核运行时不依赖预装 JDK、Python 或 Node；构建机可使用这些工具。Docker 不得拖慢 P0 闭环。

## ADR-005：离线分析，不进行工业接入和控制

- 状态：已接受
- 决策：v1 只导入 CSV、TXT、XLSX 离线文件，不实现 OPC、实时 DCS 接入或控制写入。
- 原因：缺少现场接口和授权，控制路径与本次展示目标无关且会显著扩大风险。
- 影响：界面、API、配置和演示脚本均不得出现可执行控制动作。

## ADR-006：合成数据只证明场景符合

- 状态：已接受
- 决策：无法获得脱敏真实数据时，用固定种子合成数据完成开发和验收；指标名称为“合成场景符合率”。
- 原因：合成标签由生成规则决定，不能代表真实工业分布或准确率。
- 影响：不承诺 98% 现场准确率、千万级响应或 7×24 小时工业运行；相关指标需另立数据集、硬件和验收方案。

## ADR-007：最小闭环优先于历史功能复刻

- 状态：已接受
- 决策：首先完成导入、分析、展示、处置、报告、复位的单一闭环；不增加占位页面、投机性扩展点或等价重构。
- 原因：审核日期为“尽快”，稳定可演示是首要目标。
- 影响：每个阶段必须产生可验证增量；无直接 P0 消费者的模块不创建。

## ADR-008：正式产品身份与历史事实分层

- 状态：已接受
- 决策：对外产品统一命名为“报警管理系统”。源码遗失和重新实现只保留在 `docs/backgrounds/`、`docs/sources/`、决策和验收证据中，不进入页面、报告标题、发布包标题或普通用户说明。
- 原因：当前目标已从阶段审核基线进入正式产品化，研发事故不应成为长期产品身份；历史材料仍需完整可追溯。
- 影响：合成数据声明和演示数据复位可以作为准确边界保留；不得通过批量改写历史证据来伪造连续性。

## ADR-009：无真实标签时采用 hybrid-v2 可解释模型

- 状态：已接受
- 决策：M9 采用数学化专家时序规则、一阶 Markov 关联图和可弃权原因专家模型；没有独立真实标注集时不训练 SVM/树模型，不声明真实准确率或根因证明。
- 原因：现有窗口规则具备部分泛化性，但固定分数、宽泛关键词和“步骤 1..5”事件链与合成数据耦合。
- 影响：算法必须通过未见位号、蜕变和负控测试；分数明确为规则强度，关联明确为统计建议。

## ADR-010：本机回环与网络安全部署分离

- 状态：已接受
- 决策：Windows 本机模式只绑定回环地址，允许同机 HTTP；任何非回环网络部署必须使用 HTTPS、认证和项目级授权，缺少必要安全配置时拒绝启动。
- 原因：在不修改系统信任库或制造证书假象的前提下，同时覆盖办公室单机使用和部署服务器访问。
- 影响：M11 实现并验证网络安全配置；数据库和算法端口始终不向客户端网络发布。
