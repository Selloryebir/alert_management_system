# 报警管理系统产品化蓝图

## 北极星

在 Windows 11 x64 上交付一套普通业务人员可按中文说明安装和使用、可导入新报警文件、可解释分析、可人工复核、可审计、可报告、可安全备份恢复的报警管理系统。网络部署具备身份权限和 HTTPS 边界；所有对外结论与真实证据相符。

## 阶段路线

```text
v0.1.0 可运行基线
  -> M8 正式身份与来源闭环
  -> M9 可泛化 hybrid-v2 算法
  -> M10 项目化业务与全中文 UX
  -> M11 身份权限与 HTTPS 安全部署
  -> M12 恢复、质量与运行可靠性
  -> M13 正式说明书与项目过程文件
  -> M14 Windows 业务用户终验与发布候选
  -> 人工批准正式发布
```

## 统一交付原则

- Java 21 继续承担业务入口和唯一数据库写入；Python 3.12 继续承担纯计算算法；PostgreSQL 17 继续作为唯一业务事实源；Vue 3 继续由 Java 托管。
- 不为产品化拆分微服务群，不增加消息队列、网关或兼容数据库。
- 先补用户可达闭环和可验证失败边界，再处理静态质量；不进行等价重构。
- 本机便携部署与网络部署使用同一业务实现。回环本机模式可以使用 HTTP；任何非回环网络部署必须由 HTTPS 入口和认证保护。
- 合成数据只用于功能、性能和场景回归，不作为真实准确率证明。

## 人工门禁

只有以下事项暂停自动开发：真实工业数据或设备接入、工业控制写入、客户/组织间法律责任、法规合规模板的权威确认，以及 `v1.0.0` 正式发布。其余已被产品事实和本蓝图约束的技术选择由阶段验收自动推进。
