# M15 产品工作台与工业化视觉

## 目标

把首个正式版本中纵向堆叠的业务页面重构为清晰的产品工作台，并改善大批量报警数据的可视化可读性。

## 本阶段范围

- 将 Dashboard、数据导入、分析任务、报警处置、报告审计、项目、权限、备份和运行状态拆分为独立页签。
- 保持当前项目和分析上下文跨页签连续，不引入新的路由、状态库或后端契约。
- 用面向业务价值的叙事替换贯穿业务页的演示性、弱化性说明；必要能力边界只在管理员入口集中说明。
- 建立深色工作台顶栏、紧凑导航、清晰边界和低饱和状态色组成的工业化视觉层级。
- 趋势图使用连续折线而非逐点大尺寸散点，并以大规模趋势点测试验证坐标稳定性。

## 验收标准

1. 登录后的主要能力可通过独立页签访问，同一时刻只展示当前工作区，权限不足时不出现管理页签。
2. 日常业务页面不再反复出现“Demo”“示例”“仅使用合成数据”或削弱分析价值的声明。
3. 20,000 行数据形成的多时段趋势不再由散点遮挡，折线、坐标范围和数据表保持可读、可核对。
4. 桌面与窄屏均保留可操作导航；现有导入、分析、处置、报告、权限和备份能力不退化。
5. 前端 lint、单元测试和生产构建通过，自动化控制面契约通过。

## 变更约束

- 不修改算法、数据库或 API 事实契约。
- 不把后端兼容标识改写包装成新的迁移。
- 不生成或跟踪 `.runtime`；本阶段验证使用现有前端依赖完成。
- 本地完成一个完整增量后再建立检查点；不为中间小改动推送或触发远端 CI。
