# 安全威胁模型与阶段边界

## 保护对象

- 报警原始文件、规范化记录、分析结果、人工处置和审计记录。
- 项目元数据、用户凭据、会话、配置密钥、TLS 私钥和数据库备份。
- Windows 发布目录、项目数据库目录及本项目启动的进程和端口。

## 支持的部署模式

### Windows 本机模式

浏览器、Java、Python 和 PostgreSQL 运行在同一台受控 Windows 11 电脑，服务只绑定 `127.0.0.1`。回环 HTTP 不经过局域网；启动脚本必须拒绝端口被非本项目进程占用，不修改系统信任库、防火墙或机器级环境变量。

### 网络部署模式

业务人员从其他电脑访问服务器。该模式必须使用 HTTPS、认证和项目级授权；数据库和算法端口不得对客户端网络开放。缺少证书、密钥或初始管理员配置时部署必须明确失败，不能静默回退到明文匿名服务。

## 可达威胁与控制阶段

| 威胁 | 最小控制 | 阶段 |
|---|---|---|
| 超大文件、超多行、压缩膨胀或畸形 XLSX 耗尽资源 | 上传字节、行数、工作表、单元格和解析时限上限；失败零落库 | M11 |
| SQL/表达式/路径注入 | 参数化 SQL、枚举白名单、服务端生成文件名、路径限定测试 | M11 |
| 未认证访问、水平越权、跨项目读取 | 登录、最小角色、项目作用域查询和越权负控 | M11 |
| 明文网络传输与密钥进入仓库 | 网络部署 HTTPS；密钥仅从部署环境或挂载文件读取 | M11 |
| CSRF、XSS、点击劫持和危险内容回显 | 同源会话与 CSRF、防输出注入、安全响应头、内容类型固定 | M11 |
| 备份泄露、错库恢复或破坏性卸载 | 备份路径限定、恢复目标确认、隔离恢复演练、精确实例身份 | M12 |
| 内存/CPU/磁盘/带宽失控 | 20,000 行重复运行资源观测、请求超时、无外部遥测默认值 | M12 |
| 日志泄露凭据或原始敏感内容 | 结构化最小日志、凭据/密钥扫描和失败日志复核 | M11/M12 |

## 明确非目标

- 本系统不连接或控制 DCS/PLC，不提供联锁、远程控制或自动处置写入。
- 当前阶段不宣称互联网多租户 SaaS、国家密码合规、等保认证或渗透测试结论。
- 没有真实组织、用户和现场数据前，不虚构组织级隔离或合规证明。

这些非目标不取消基本输入校验、认证授权、HTTPS 和安全脚本要求。
