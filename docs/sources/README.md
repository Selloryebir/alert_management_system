## 使用约束

- 开发智能体不得直接将本目录中的历史陈述视为当前需求、架构决策或验收结果。
- 后续应在产品事实层对候选需求进行采纳、改写或屏蔽，并保留到本目录页码/章节的追踪关系。
- “已完成”“测试通过”“准确率”“响应时间”“合规”等声明在当前重建项目中一律视为 `unverified`。
- 机器可读的来源文件身份见 [manifest.json](manifest.json)，各来源的提取边界见其子目录 manifest。
