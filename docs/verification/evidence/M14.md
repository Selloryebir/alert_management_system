## 对抗审计与缺陷闭环

部署、安全、算法、UI 和文档三路独立审计首先提出以下真实缺陷，随后均按最小范围修正并由上述门禁覆盖：

- Compose 手工准备错误依赖被忽略的开发虚拟环境，且残缺模型会阻断后续启动；现已分离密钥职责并支持模型原子生成/精确恢复。
- Windows 英文区域控制台不能输出训练状态；现强制 UTF-8，远端 Windows 已经过该路径。
- 常见中文正常运行描述和英文 `abnormal` 子串会造成低级误判；现加入 Unicode 归一化、词边界和高置信否定/正常语义保护。
- 原验证数据与训练结构重复；现按组、文本和结构签名隔离，并公开保守接受率与适用边界。
- Dashboard 缺少可见刷新和数据时间，导入网络错误缺少警报语义；现提供数据库快照时间、刷新入口与 `role=alert`。
- 公开源码曾保留内部目录断链和早期编写叙事；现由净化导出器阻断禁止路径、词语和相对断链。
- 开发启动从空目录缺少模型；现仅在开发入口原子重建，并由本地两轮启停及远端 M1/M12 验证。
