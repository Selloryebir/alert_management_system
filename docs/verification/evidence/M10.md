## 实现范围

M10 在既有 Java 单体、Python 算法服务、Vue 前端和 PostgreSQL 数据库边界内补齐项目化业务，不引入通用工作流、模板引擎或第二套业务实现：

- 项目成为导入、分析、处置、审计和报告的统一业务作用域，支持创建、选择、编辑、归档、恢复和只删除已归档空项目。
- 两个项目的批次、报警、分析结果、概览、处置和报告相互隔离；项目报告名和正文均包含项目身份。
- 业务人员通过下拉框完成源表头到目标字段的图形化映射，不编辑 JSON。
- 被拒绝行可在页面按字段修正后随原文件重新全量校验；原始 `raw_payload` 保留，修正值单独追溯。
- 支持人工补录、编辑和作废报警，并在项目概览与任务列表中反映真实状态。
- 六步首次使用引导由真实业务状态驱动，覆盖项目、文件、映射、导入、分析、处置和报告。
- 状态、分类、审计事件和当前后端能够产生的 13 种导入错误码均显示为中文；专有名词和稳定 API 机器值只保留在协议与证据中。

Flyway 仅新增 V7 项目作用域和 V8 导入修正迁移，不修改 V1–V6。Java 仍是浏览器唯一入口和数据库唯一写入者；Python 算法协议及 hybrid-v2 计算不变。
