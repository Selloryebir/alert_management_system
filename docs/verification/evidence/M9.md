## 实现范围

M9 用真实可计算的 hybrid-v2 替换 v1 占位式规则：

- 重复报警按关系键、位号、核心字段和正时间差计算指数衰减强度。
- 抖动报警用前缀变换和区间最小值查询识别全部合法窗口，时间复杂度为 `O(n log n)`；逐记录解释只保留固定长度统计摘要。
- 短时、持续报警按 `return_time`、`ack_time` 和显式阈值判定。
- 原因分类使用非负专家权重余弦分数、最低分和类别间距；证据不足或冲突时保留 `UNKNOWN`，不把分数称为概率或准确率。
- 关联链按 `site/area/unit` 划分 episode，折叠连续同 tag 状态，以一阶 Markov 的 episode 支持度、`P(v|u)`、基线 `P(v)`、lift 和中位时延发现；解释明确“统计关联不代表已确认根因”。
- 浏览器在分析前可配置 14 个有类型和范围的模型参数，分析完成后显示实际参数、契约、组件和规则版本。

Java 仍是唯一浏览器业务入口和 PostgreSQL 写入者；Python 仍是无数据库权限的纯计算服务。浏览器接口继续使用 `/api/v1/**`，Java 与算法之间使用 `/api/v2/analyze`。Flyway V6 只把事件链长解释列扩展为 `TEXT`；旧 v1 分析结果仍可读取。

## 泛化与隔离证明

运行时代码不读取合成场景名、固定源行、步骤命名、固定 UUID 或预期结果文件。独立黑盒覆盖：

- 未见 tag 与中性描述的三 episode Markov 正例；支持不足、随机顺序、跨关系借用和超窗时延负例。
- 输入乱序、整体时间平移、UUID 重映射、`raw_payload` 扰动和重复调用确定性。
- `return_time`、ACTIVE/ACK 边界、重复报警正时间差和抖动内部窗口。
- M8 强度定义更正反例：索引 1–6 命中，末条强度固定为 `0.8`。
- 500 条同时间抖动组与三段各 400 条 Markov 长链，约束逐记录解释总量线性增长。

固定 smoke 数据由独立生成器 `2.0.0` 生成，CSV 摘要为 `f8a2b4dcb5a6629839330689681867ee37d82fdc752266ca610bf6ddbf43b8a2`。300 条结果为：噪声 `NORMAL=170、DUPLICATE=30、CHATTER=40、SHORT_LIVED=30、PERSISTENT=30`；原因 `PROCESS_DISTURBANCE=30、EQUIPMENT_FAULT=30、INSTRUMENT_ISSUE=30、MAINTENANCE_TEST=20、UNKNOWN=190`；事件链 12 条。
