## 实现范围

候选生成一个解压即用的 Windows x64 ZIP。运行时内含 Microsoft OpenJDK 21.0.12.1 jlink JRE、Python 3.12.14 算法服务、PyInstaller 6.22.2 onedir 和 PostgreSQL 17.11；Node.js 22.22.1 只用于构建和验收，不进入发布包。Demo 运行不依赖预装 JDK、Python、Node、WSL 或 Docker。

发布脚本提供预检、启动、停止、项目数据库备份和限定业务数据复位。三个服务固定监听 `127.0.0.1` 的 55432、8001、8080；PID 记录同时保存实际可执行路径、命令行、工作目录、真实发布根和日志。中文路径下，PostgreSQL 与 Java 复用一个位于用户临时目录、目标经过精确核对的 ASCII Junction；实际数据、日志、备份和样例仍位于发布包，算法仍从真实发布根运行。停止和失败清理只处理身份与当前发布根或其精确 Junction 相符的进程。

本阶段没有修改业务 API、Flyway 迁移、算法规则或页面语义，也没有建设安装器、Windows 服务、自动更新、动态端口、权限系统或第二套业务实现。
