## 实现范围

候选只增加 `postgres`、`algorithm`、`backend` 三个 Compose 服务。Vue 仍由既有构建产出并打入 Java JAR；Java 仍是唯一业务入口和 PostgreSQL 事实写入者；Python 算法服务仍不连接数据库；Flyway 仍由 Java 启动时执行。只有后端的 `127.0.0.1:8080` 发布到宿主机，数据库和算法端口不发布。
