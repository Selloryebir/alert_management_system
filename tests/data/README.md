# 合成数据验证

运行：

```bash
python3 -m pytest tests/data -q
```

测试仅使用 Python 标准库读取 CSV、TXT 和 XLSX，并调用合成数据生成器。它验证正式短集三种格式规范化后完全一致、十二类业务行为均有数据覆盖且运行时字段不含场景名、非法文件边界与清单一致、所有已提交样例可逐字节重建，以及 20,000 行长集可由固定种子重复生成。

摘要常量独立于 Java 导入实现。数据测试不声称后端已经原子拒绝非法批次；该行为由后端和跨组件集成测试负责。生成器或契约有意变更时，必须人工审阅样例差异后再更新常量，不得由待测 Java 代码生成预期结果。
