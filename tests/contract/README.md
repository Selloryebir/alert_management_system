# M3 独立黄金预期测试

本目录验证 `samples/expected/analysis-smoke-expected.json` 与固定 Smoke 输入和数据契约一致。黄金答案由测试组按冻结的 `source_row` 场景区间建立，不导入、不调用算法服务，也不读取算法输出。

运行：

```bash
python3 -m pytest tests/contract -q
```

测试覆盖：

- Smoke 输入 SHA、场景顺序及 2–301 行号连续性；
- 重复对、抖动频次/窗口、短时恢复、已确认持续报警等规则前提；
- 300 条记录的逐行分类覆盖和固定计数；
- 12 条五步骤事件链的时间窗、成员顺序及无重复；
- 黄金 JSON 的逐字节可重建性。

算法实现只能消费该预期进行验证，不能修改本目录以使自身输出通过。规则语义或样例变化时，应由测试组依据数据契约重新审阅，不能从算法实际输出反向生成答案。
